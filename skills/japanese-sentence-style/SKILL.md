# 日本語の一文レベルの書き方

一文の中で読点をどこに打つか、文をどこで切るか、語をどう並べるかのルール。

## 読点

読点は、係り受け・並列・節の切れ目といった文の構造を示すために打つ。息継ぎや飾りの区切りとしては打たない。区切りが見て分かる短い句の後には打たず、長い句の後や誤読が起きる場所には打つ。

AIのドラフトは、主語や文頭の接続語の直後に機械的に読点を入れ、長い文を読点で刻んで成立させがちである。書き終えたら読点を1つずつ「消しても読めるか」で点検する。

### 打つ読点

- 並列の区切り。ただし名詞の並列は中黒「・」を第一選択にする（「追加・削除・移動」）。読点で並べるのは、要素に括弧や中黒を含むときと「①〜、②〜、③〜」の列挙のとき
- 逆接の接続助詞の直後（「〜が、」「〜ものの、」）
- 理由の接続助詞の直後（「〜ので、」「〜ため、」）は、後続が長いときに打つ。後続が短ければ打たない
  - 打つ「楽しんでいるクリエイターが好きなので、そういう意味で良い発表だった」
  - 打たない「脱予算経営のことを全く知らなかったので勉強になった」
- 長い主語・長い目的語の直後（「このオプションは、設定ファイルより環境変数を優先するかどうかを決めるフラグで」）
- 長い修飾語が2つ以上並ぶときの境界
- 「〜る、という」のまとめ受け（「レビュー前に自分で一度読み直す、という習慣」）
- 順序副詞の直後（「まず、」「次に、」「続いて、」「最後に、」）
- 比況「Xのように、」の直後（「前回の障害のように、原因が複数重なる場合は」）
- 同じ助詞が連続するのを避けるとき（「移行作業を、既存機能を止めずに進める」）

### 打たない読点

- 文頭の接続語・話題提示の直後: 「この記事では」「今回は」「ここでは」「これで」「ただし」「そこで」「次は」「それでは」「たとえば」「Nつ目は」
  - NG「今回は、手元の環境で再現手順を確認した」→ OK「今回は手元の環境で再現手順を確認した」
- 短い主語・主題・目的語・手段句の直後（「Xは、」「Xを、」「Xで、」「〜ごとに、」）
  - NG「設定ファイルを、リポジトリ直下に置きます」→ OK「設定ファイルをリポジトリ直下に置きます」
- 短い連用中止・条件節の直後（「〜して、」「〜を使って、」「〜すると、」「〜たら、」「〜前に、」）
  - NG「ブランチを切って、PRを作ります」→ OK「ブランチを切ってPRを作ります」
- 副詞の直後（「もちろん」「実際に」「特に」「基本的に」「結果的に」）
- 閉じ括弧「」の直後。引用は「〜と」で受けて流す

### 「打たない」場所でも打つ例外

- 後続が非常に長いとき（「たとえば今回の移行では、旧環境で動いていたバッチを止めずに…」のように後続が80字近い）
- 消すと同じ文字種が続いて語の切れ目が見えなくなるとき（「では、いよいよ」「それでは、ここから」「これで、やりたかったことが」）
- 直後に読点で区切った並列が続き、読点なしだと並列の切れ目と紛れるとき（「これで、テストを実行する処理と、結果を集計する処理が」）

### 削る以外の手

- 主語直後の読点は、消すのではなく長い修飾句の切れ目へ移す
  - NG「バッチは、1日に1回全ユーザーの集計を更新する」→ OK「バッチは1日に1回、全ユーザーの集計を更新する」
- 語を書き換えて読点をなくす（「毎回、」→「そのたびに」、「毎日、」→「日次で」）
- 読点が3つ以上ないと読めない文は、列挙でない限り文を分ける
- 同型の文が並ぶときは読点の有無を揃える

## 文の分割

文を分けるかどうかは長さでなく構造で決める。主語から述語まで一本道で読める文なら、長くても読点なしで通る。

- 一文の論点は1つにする。連用中止「〜し、〜し、」で論点をつなげた文は分ける
- 読点を3つ以上足さないと読めない文や、係り受けが2通りに取れる文は、読点を足すのではなく分けるか語順を直す
- 並立する情報を3つ以上並べるときは、箇条書きを検討する

## 語順

- 長い修飾語を先に、短い修飾語を後に置く。この語順を守ると読点は自然に減る
  - NG「Aは、Bを使ってCするためのDを、Eに定義する」→ OK「Aは、CするためにBを使うDをEに定義する」のように、長い句を前に寄せる
- 節（述語を含む修飾）を先に、句（名詞的な修飾）を後に置く
- 語順を原則と逆にせざるを得ないときは、その境界に読点を打つ

## 並列

- 名詞の並列は中黒「・」でつなぐ
- 要素が長い、要素に括弧や中黒を含む、番号付きで列挙する、のいずれかなら読点で区切る
- 節の並列（「〜し、〜する」）は2つまでにし、3つ以上なら文を分けるか箇条書きにする
