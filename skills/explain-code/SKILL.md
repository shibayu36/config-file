# explain-code

「知りたいこと」を、このコードを初めて見る開発者向けに、1つの自己完結したHTMLで解説する。

- 「知りたいこと」に答える構成にする。それが広すぎて答える範囲が定まらないときだけ、生成前に1〜2問聞いて絞る。問いを推測して勝手に増やさない
- 大きな絵と少ない言葉で、上から順に読める一本道の物語にする
- 具体例を1つ軸に決めて、その値が各段階でどう形を変えるかを絵の中で追う。性質の違う例が必要なら短く足す
- ルールや分岐には「なぜそうなっているか」を一言添える
- 関係するメソッドの関係を1つの図に整理する。各メソッドは責務を1行で、矢印には「何を渡すか」を書く
- 絵や本文で file:line を指す箇所は、クリックすると本文と並べて読めるサイドバーにメソッド本体が開くようにする。本体は実ファイルから省略せず写し、分かりにくい行の右に短い注釈を付ける。推測で書いたコードを実コードのように見せない

生成したファイルのパスを報告する。「ここをもっと詳しく」と頼まれたら新規作成せず同じファイルに追記する。

知りたいこと: $ARGUMENTS
