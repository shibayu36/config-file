# explain-code

このコードを初めて見る開発者に向けて、1つの自己完結したHTMLで解説する。

- 「何がきっかけで、どこを通って、何が結果になるか」の順に組み立てる。コードの並び順ではなく出来事の順で説明する
- 抽象から具体へ3段で深める。まず責務の箱と境界だけの図、次に具体的なシナリオで各段階の値がどう変わるかの表、最後にコード
- シナリオは複数用意する。正常系・上書き・衝突・不正入力のように性質が違うものを選び、既存のテストから拾えるならテスト名を添える
- コード抜粋は短く絞り、重要な行に行注釈を付ける。抜粋を貼るだけで説明した気にならない
- 必ず実コードを読んでから書き、推測したコードを実コードのように見せない
- 冒頭に「この文書が答える問い」を並べ、各セクションがどの問いに答えるか分かるようにする

差分の解説なら変更前後のコードと「なぜそう変えたか」を並べる。生成したファイルのパスを報告する。「ここをもっと詳しく」と頼まれたら新規作成せず同じファイルに追記する。
