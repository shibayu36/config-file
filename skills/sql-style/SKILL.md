# SQLを書くときのルール

## エイリアス

- テーブル名にはエイリアスを付けない。付けてよいのは、同じテーブルを複数回結合するときだけ
- SELECTするカラム名は基本そのまま使う。エイリアスを付けてよいのは、変えた方が確実に分かりやすくなるときだけ
