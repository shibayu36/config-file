# ノンデザイナーのためのビジュアルデザインの原則

目指すのは、独創的な見た目ではなく、読みやすく一貫した見た目である。以下の「1画面」は、ページ・スライド1枚・動画の1場面のような、一度に目に入る単位を指す。

## 方針

- 既にあるスタイル・コンポーネント・テンプレートがあれば、それに合わせる。それらが値を決めている部分はそれに従い、以下の規則はそれらが決めていない部分に使う
- 見た目を良くしたいときは、装飾を足す前に配置と余白を直す

## 作るときの進め方

次の順に決める。

1. **焦点**: 読み手に真っ先に見てほしいものを1つ決め、強いコントラストで目立たせる
2. **近接**: 情報を論理的なグループにまとめる。関連する要素は近づけ、関連しない要素は離す
    - グループ間の空きは、グループ内の空きよりはっきり広くする
    - 1画面で視線が止まる箇所が3〜5個を超えるなら、1つのグループにまとめられるものがないかを見る
    - どこから読み始め、どこで読み終わるかの流れが、1本で追えるようにする
3. **整列**: すべての要素を、他のどれかの要素の端に揃える。離れた要素どうしも、揃えられる端を探す
    - 文字揃えは1画面で1種類にする。左揃えと中央揃えを同じ画面で混ぜない
    - 中央揃えは、フォーマルで静かな印象を意図して作るときだけ選ぶ。それ以外は、縁の線が強く出る左揃えにする
4. **反復**: 既にある一貫性（見出しの書体、罫線、番号の書き方、配置など）を見つけ、全体で同じように繰り返す。同じ役割の要素には同じスタイルを使う
5. **コントラスト**: 違うものは、はっきり違える
    - わずかなサイズ差、わずかな太さの差、似た色どうし、似た書体どうしは、差ではなく衝突に見える
    - よく似た書体を複数使わない
    - すべてを大きく太く派手にしない。強調は焦点と見出しに絞る

## 文字

- 日本語の行間は、アルファベットの行間の1.2倍程度に広げる。ツールやフレームワークの初期値はアルファベットを基準にしていることが多く、日本語には狭い

## レビューするとき

見た目のレビューでは、レンダリング結果を見て確かめる。レビュー以外で作る・直すときは、レンダリング結果を確かめなくてよい。

- 指摘には、場所と、反している原則を書く。原則に反している箇所がなければ、指摘も変更もしない
- 指摘に基づいて直すときは、重要な問題から直す。直した後はもう一度レンダリングし、直した箇所が新しい不揃いを作っていないかを確かめる
